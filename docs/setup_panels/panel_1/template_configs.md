# Hardcoded

We have the teacher define every question and when to trigger them, either at a certain time or manually (all questions are manually triggerable later in the interface).

# Automated

We ask the teacher whether they want the LLM to decide when to trigger questions or whether they want to do it manually/at an interval/at an interval with consent (ask first).

# Worriless

Absolutely nothing, skipped.

# Customized

Full customization: we allow the teacher to define a layout of questions/hidden answers and allow them to set up an LLM to ask questions dynamically alongside as well.
